How each report is placed

By where it came from, not by what intake guessed. Intake’s parser/hint tag comes from the reporter’s browser, and the tenant decides the cause (apps/kb/lib/kb/causes.ts). The desk’s reading of a report as a one-day move comes first, so no report counts twice (apps/kb/lib/kb/problems.ts). The export repeats some reports across pages; each id counts once.
